\# Sources and Inspiration



This file documents external sources used during the development of the project.



\## Brutus



Praetorian Inc., Brutus:

https://github.com/praetorian-inc/brutus



Usage:

\- Brutus is the main credential-testing tool used in this assignment.

\- The repository is used as a reference for installation, configuration and usage.

\- No Brutus source code is copied into this project.



\## FTP / vsftpd



The FTP target uses the Debian `vsftpd` package.



The FTP Docker configuration was written specifically for this project.



No external vsftpd configuration was copied directly into the project.



\## SSH and Telnet



The SSH and Telnet targets use standard Debian packages.



The Dockerfiles and laboratory configuration were created specifically for this project.
